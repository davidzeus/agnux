AGNUX OS

Sistema Operativo diseñado para integrarse nativamente sobre un Kernel de Linux, propulsado por Inteligencia Artificial y blindado por Cloudflare Zero Trust.

Ingeniería del Núcleo

Autogénesis de Código

El Kernel posee la asombrosa capacidad de escribir, compilar e inyectar código Python dinámicamente en tiempo de ejecución. AGNUX programa sus propias *Tools* evolucionando sobre la marcha sin reinicios.

Recuerdos Criptográficos

Conectado a Qdrant, AGNUX almacena memorias semánticas vectoriales a largo plazo. Aprende de tu estilo, recuerda tus preferencias pasadas y cruza información antigua para deducir contextos complejos de forma persistente.

Seguridad Zero Trust

La infraestructura está blindada detrás de túneles oscuros de Cloudflare. Se han eliminado las vulnerables VPNs; el acceso se rige por aserción criptográfica directa al Kernel.

Hardware Recomendado

Inferencia pura en local. Requiere CPU Multi-Core Moderno, mínimo 16GB de RAM (32GB recomendados) y GPU dedicada (NVIDIA RTX 3060+ de 8GB+ VRAM) para operar las bases de datos vectoriales en tiempo real.

Ecosistema de Herramientas

El Kernel no solo responde texto, ejecuta acciones sobre sistemas reales interactuando mediante su suite de utilidades auto-escritas.

Integración Google Workspace

Acceso bidireccional a los servicios de Google Cloud. AGNUX es capaz de leer correos de Gmail, redactar borradores, y manipular documentos en Google Docs directamente desde la terminal principal.

Media Core Integrado

AGNUX controla de forma inmersiva un reproductor multimedia en ventana flotante, siendo capaz de buscar videos o audios y proyectarlos en el escritorio de forma nativa a pedido del usuario.

Matemáticas Computacionales

Para no alucinar números, la IA cuenta con una herramienta exacta capaz de delegar ecuaciones, aritmética compleja o cálculos de servidor directamente al procesador local para obtener 100% de precisión.

Scraper de Tiempo Real

El sistema obtiene datos en vivo de la red, como consultar reportes del clima, extraer el precio de criptomonedas o raspar sitios web para inyectar la realidad externa dentro del razonamiento interno del LLM.

Filosofía de Desarrollo

El Stack Tecnológico: ¿Por qué Python, Angular y Agno?

AGNUX OS está diseñado con un objetivo claro: la democratización del desarrollo de IA. Podríamos haber construido el Kernel en lenguajes de bajo nivel y altísimo rendimiento como Rust o C++. Sin embargo, su extrema curva de aprendizaje, el estricto manejo de memoria y los lentos tiempos de compilación levantan un muro impenetrable para el 90% de los creadores. AGNUX no busca ser una caja negra incomprensible, sino un terreno de juego abierto.

Elegimos Python junto al marco de agentes Agno porque Python es el lenguaje nativo de la inteligencia artificial. Esto permite la verdadera magia de AGNUX: la Autogénesis. El sistema puede escribir, inyectar y ejecutar sus propias herramientas de forma instantánea. Si un usuario quiere alterar el núcleo, solo necesita leer código humano, sin lidiar con punteros ni compiladores estrictos.

Para la interfaz gráfica, Angular (TypeScript) nos otorga el equilibrio perfecto. Permite iterar interfaces reactivas, fluidas y profundamente inmersivas a la velocidad frenética de la web, pero manteniendo la estructura rígida y robusta necesaria para simular un Sistema Operativo completo en cualquier pantalla.
